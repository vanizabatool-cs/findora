# Findora — Smart Campus Lost-and-Found

Findora is a campus platform designed to help students report lost and found items, search reports, and discover possible matches using data structures and algorithms.

## Planned Features
- Report lost items
- Report found items
- Search and filter reports
- Rank possible matches and explain matching reasons
- Manage claim and return status

## Technology Stack
Java · HTML · CSS · JavaScript · Spring Boot · PostgreSQL
